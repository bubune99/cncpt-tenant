# Managing Sites

Each site you create gets its own subdomain, editor, and content. Here is how to manage them effectively.

## Creating a Site

1. Click **Create New Site** on the dashboard.
2. Choose a starting point: blank canvas, template, or import from an existing project.
3. Enter a site name and subdomain.
4. Click **Create** — you will be taken straight to the editor.

<Callout type="tip">
Subdomains must be unique across the platform. Keep them short and descriptive (e.g., `portfolio`, `shop`, `blog`).
</Callout>

## Editing a Site

Open any site from the dashboard to enter the visual editor. The editor supports:

- **Drag-and-drop blocks** — Headings, paragraphs, images, sections, buttons, videos, and more.
- **Inline text editing** — Click any text block and type directly on the canvas.
- **Style controls** — Adjust colors, spacing, typography, and responsive behavior from the properties panel.
- **Undo/Redo** — Full history with `Ctrl+Z` / `Ctrl+Shift+Z`.

## Duplicating a Site

Need a copy of an existing site? Click the **three-dot menu** on any site card and select **Duplicate**. This creates an exact copy with a new subdomain. Useful for:

- A/B testing different designs
- Creating seasonal variations
- Starting a new project from a proven layout

## Site Settings

Each site has its own settings panel accessible from the editor toolbar:

- **SEO** — Page title, meta description, Open Graph image.
- **Favicon** — Upload a custom favicon for the site.
- **Analytics** — Connect Google Analytics or use built-in tracking.
- **Status** — Toggle between Published, Draft, and Maintenance modes.

## Deleting a Site

To delete a site, open the site settings and scroll to the danger zone. Deletion is permanent after a 30-day grace period during which you can restore the site from the dashboard.

<Callout type="warning">
Deleting a site also removes its custom domain connections. Make sure to update your DNS records if needed.
</Callout>

## Site Limits

The number of sites you can create depends on your plan:

- **Starter** — 1 site included, additional sites available as add-ons.
- **Growth** — Up to 3 sites included.
- **Pro** — Up to 10 sites included.
- **Business** — Unlimited sites.
